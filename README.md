# ErrorBot Site

## Deployment

The site is currently hosted by Cloudflare at https://kyleanderror13.pages.dev/. Cloudflare is directly connected to the git repo, meaning that updates to the repo automatically build and deploy the site.

## Technology

The site is built with Vue/PrimeVue using TypeScript.

## Guide

Use 'npm run dev' from the terminal to run the dev server. Connect to the dev server at http://localhost:5173/. The site will hot-reloaded when it detects code changes to the source.
